# 核心女性角色卡：许知微

> **归档路径**：`characters/03_核心女配_许知微_角色卡.md`  
> **角色定位**：首席智囊 · 制度派合作者 · 高山流水型红颜知己

## 一、基础档案

| 属性项 | 详细设定 |
| :--- | :--- |
| **姓名** | **许知微**（初登场称“文书阁素袍女子”） |
| **身份演进** | 外院文书阁一楼执事（第9章）→ 文书阁二楼典籍执事（第53章）→ **内门藏经阁司书**（第80章因举荐百艺魁首沈梦天记大功一次，定于今夏正式调升） |
| **修为与灵根** | 炼气七层（炼气后期），水木双灵根 |
| **外貌与气质** | 常年穿一袭素白执事道袍，发髻用一根素银簪一丝不苟地挽起；眉目清冷疏离，眼神如古井寒潭般透彻冷静，说话惜字如金、直奔利害。 |
| **合规基线** | **完璧之身**。出身青云山脚没落书香散修之家，靠自身算学与过目不忘之能考入文书阁，无任何道侣或既往婚恋史。 |

## 二、性格特征与相处模式

1. **绝对理智的“等价交换主义者”**：
   * 她从不相信无缘无故的善意，也绝不会因为个人好感而替沈梦天违规兜底。
   * 从第 9 章沈梦天拿《旧账损益速查表》换取半个时辰查阅权开始，到第 18 章《十年山界水患简表》、第 35 章《三十六种药渣湿气折耗表》、第 67 章《赤阳草异常品控报备单》，再到第 76 章她主动拿出《内门丹堂派系及百艺考较详录》押注沈梦天冲前三——两人的每一次合作都建立在**“聪明人之间无需多言的利益互换与绝对默契”**之上。
2. **知分寸、守边界的智识欣赏**：
   * 她是全书第一个看穿沈梦天“表面老实本分、实则每一步都提前半个月焊死免责退路”的人。她欣赏沈梦天在算学、制度拆解与危机预判上的惊人天赋，沈梦天也敬重她的清醒与守信。
3. **后续内门剧情功能（第 81 章起）**：
   * 调升**内门藏经阁司书**后，她将成为沈梦天获取内门高阶功法残卷、上古百草宗体质秘录（破译温见微【先天太阴调谐脉】进阶之法）以及内门崔氏等门阀派系动向的核心情报源。
