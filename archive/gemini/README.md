# Gemini 交付归档总索引

本目录保存已接收的 Gemini 版本交付原件，以及 GPT 对每一轮交付的独立审查记录。

## 归档规则

每个版本独立建目录，建议结构：

```text
Vx.y.z/
├── 原始交付/       # Gemini 原文件，原样保存
├── 审查报告.md     # GPT 独立审查结论，不覆盖原件
└── 版本索引.md     # 文件清单、来源提交、归档时间、审查状态
```

原始文件只归档、不改写。任何修订都应作为新版本提交。待交付区清空前必须核对文件数量和归档完整性。

## 审查状态说明

- **已归档**只表示文件已安全保存，不代表内容通过审查。
- **审查不通过**表示存在明确问题，必须完成后续修订和复核。
- **待作者裁决**表示方案之间存在取舍，不能由执行模型擅自定为正式设定。
