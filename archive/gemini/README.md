## 状态说明

- **不通过**：存在明确问题，不得作为正文唯一执行依据。
- **部分通过，需补正**：主体方向有价值，但仍有明确缺陷；不得直接作为正文写作依据。
- **专项返修通过**：本轮指定问题已修复，不等于全稿终审或作者批准。
- **待作者裁决**：多个方案尚未获作者批准。
- **已归档**：原始交付已保存，不代表审查通过。
- **已验收**：仅在独立审查通过且作者确认后使用；不得由交付方自行标记。
