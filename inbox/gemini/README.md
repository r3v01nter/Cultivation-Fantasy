# Gemini 交付入口

本目录只负责接收新一轮交付。已审查的成果统一转入 `archive/gemini/`，不在本目录长期堆放。

## 唯一交付入口

将每轮 Gemini 的全部交付文件直接放入：

`inbox/gemini/待交付/`

不要在本目录根目录新建版本目录，也不要自行判断归档位置。

## 固定处理流程

1. 用户投递本轮文件。
2. GPT核对文件完整性并独立审查。
3. GPT将原始文件原样归档到 `archive/gemini/对应版本/原始交付/`。
4. GPT另存审查报告与版本索引。
5. 确认文件数量、内容和归档完整性后，清空待交付区，仅保留Git占位文件。
6. GPT向用户报告审查结论、归档位置和下一轮任务。
