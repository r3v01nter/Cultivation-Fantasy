# Gemini 交付入口

本目录只负责接收新一轮交付。已审查的成果统一转入 `archive/gemini/`，不在本目录长期堆放。

## 唯一交付入口

将每轮 Gemini 的全部交付文件直接放入：

`inbox/gemini/待交付/`

不要在本目录根目录新建版本目录，也不要自行判断归档位置。每轮交付请在文件名中标明版本号，例如 `V6.8.5_...`；README可保留为本轮文件清单。

## 固定处理流程

1. 用户将本轮全部文件投递至唯一交付入口。
2. GPT核对文件数量、命名、相互引用及任务书要求，并独立审查。
3. GPT将原始文件原样归档到 `archive/gemini/对应版本/原始交付/`。
4. GPT另存独立审查报告与版本索引。
5. 核验归档文件数量和内容完整后，清空待交付区，仅保留 `.gitkeep`。
6. GPT向用户报告审查结论、归档位置和下一轮任务。
