# Gemini交付入口

本目录用于接收作者手动提交的Gemini交付文件。Gemini不直接写入或提交本仓库。

## 唯一交付位置

作者将本轮解压后的全部交付文件整体提交到：

`inbox/gemini/待交付/`

文件直接放在待交付区根目录，不建立版本子目录，不需要作者逐份分类或改名。文件名应能识别任务版本，例如 `V6.8.7_...`。若交付包中包含无关临时文件，作者无需自行筛选，由ChatGPT审查时识别处理。

## 固定流程

1. ChatGPT发布中文任务书，并提供GitHub页面链接和Raw下载链接。
2. 作者将任务书链接或下载文件交给Gemini。
3. Gemini阅读任务书指定资料，按指定文件名、格式和数量完成全部文件；完成自检后，将交付文件整理成一个清晰的压缩包发送给作者，并附文件清单及自检结果。
4. 作者只需解压，并将解压得到的本轮交付文件整体上传到待交付区；无需逐份打开、分类、改名或整理。
5. ChatGPT读取待交付区的全部文件，核对文件数量、命名、引用关系和任务要求，独立审查。
6. 审查后由ChatGPT将原始文件原样归档至 `archive/gemini/对应版本/原始交付/`，另写审查报告与版本索引。
7. 完成归档核验后，ChatGPT清理待交付区，使其恢复为空，仅保留 `.gitkeep`。

## 职责边界

- **Gemini：** 只负责执行任务、生成文件、自检、打包并发送给作者；不操作GitHub，不负责仓库上传、归档或清理。
- **作者：** 只负责接收、解压并整体上传交付文件；不承担逐份分类、改名和归档工作。
- **ChatGPT：** 负责读取全部交付、独立审查、整理归档、维护索引并清理待交付区。
