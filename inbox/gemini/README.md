# Gemini 附件投递区

这里存放 Gemini 输出后、等待审阅的原始材料。收件箱内容默认属于提案，不自动成为正文事实或正式设定。

## 工作流程
1. Gemini 将每轮交付放入独立版本目录。
2. 保留原始文件和版本，不覆盖旧交付。
3. 审阅文件完整性、事实依据、跨文档一致性与逻辑。
4. 审阅后标注通过、需修改、待裁决或归档。
5. 只有作者明确批准后，才将内容合并到正式设定或正文目录。

## 重要规则
- 本目录是收件区，不是正式资料库。
- 不得仅凭文件名中的“定稿”“最终版”或自检表中的“已解决”认定内容通过验收。
- 不自动替换 `manuscript/`、`characters/` 或 `docs/` 中的文件。
- 不覆盖或删除历史版本；整理时保留原始内容和可追溯提交记录。
- V1 正文与 V2 重构提案严格分开。
