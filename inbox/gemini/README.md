# Gemini交付入口

本目录用于接收作者手动提交的Gemini交付文件。Gemini不直接写入或提交本仓库。

## 唯一交付位置

作者将检查后的本轮全部交付文件提交到：

`inbox/gemini/待交付/`

请将文件放在该目录根目录，不建立版本子目录。文件名应标明任务版本，例如 `V6.8.6_...`。

## 固定流程

1. ChatGPT发布中文任务书，并提供GitHub页面链接和Raw下载链接。
2. 作者将任务书链接或下载文件交给Gemini。
3. Gemini自行浏览仓库中任务书指定的资料，完成工作后将全部文件发送给作者。
4. 作者检查交付内容，并手动提交至本目录的待交付区。
5. ChatGPT核对文件数量、命名、引用关系和任务要求，独立审查交付。
6. 审查后由ChatGPT将原始文件原样归档至 `archive/gemini/对应版本/原始交付/`，另写审查报告与版本索引。
7. 完成归档核验后，待交付区恢复为空，仅保留 `.gitkeep`。
