# Gemini交付入口

本目录用于接收作者手动提交的Gemini交付文件。Gemini不直接写入或提交本仓库。

## 唯一交付位置

作者将本轮解压后的全部交付文件整体提交到：

`inbox/gemini/待交付/`

文件直接放在待交付区根目录，不建立版本子目录，不需要作者逐份分类或改名。

## 固定流程

1. ChatGPT发布中文任务书，并提供GitHub页面链接和Raw下载链接。
2. 作者将任务书链接或下载文件交给Gemini。
3. Gemini按任务书生成全部文件、自检、打包并发送给作者，不操作GitHub。
4. 作者解压后将本轮交付文件整体提交到待交付区。
5. ChatGPT读取全部文件并独立审查。
6. 审查后将原始文件原样归档，另写审查报告和版本索引。
7. 归档核验完成后清空待交付区，仅保留 `.gitkeep`。
