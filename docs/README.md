## 归档目录建议

合并正文已经归档。若后续需要拆分单章，按以下结构管理并逐章校验：

- `manuscript/01_80.md`：第 01—80 章定稿合并正文（原文原样保存，已完成）。
- `chapters/001_第一章_送尸人.md` 等：单章拆分待办；必须由定稿原文拆分并校验章标题、顺序与正文完整性。
- `volumes/`：如确有分卷发布需求，再从单章正文生成分卷合集，避免多份互相漂移的“主稿”。

## 维护规则

1. 不改写定稿正文；任何修订另建版本并经作者确认。
2. 章节正文是事实来源，摘要和台账是索引，不能反过来取代正文。
3. 所有剧情记录标注来源章节；正文未明确的内容标为“待定”。
4. 角色推断、已证事实和作者尚未决定的设定分开记录。
5. 每次续写后同步更新导航、进度、人物/物件状态和时间线。
6. 仓库保持 Private；提交前确认没有意外改变可见性。
