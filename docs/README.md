## 维护规则

1. 正文优先；目录、摘要、设定和台账不得反过来取代正文。
2. 不改写第 01—80 章定稿正文。任何正文修订另建修订稿并经作者确认。
3. 事实、角色推测、作者待定事项必须分开标记，并注明来源章节。
4. 不创建重复的单章正文副本，除非作者明确要求拆分；如拆分，必须由定稿机械拆分并校验。
5. 每次新增正文后同步更新导航、人物/物件状态、时间线、伏笔和路线状态。
6. 第 80 章以后的计划不能写成已发生剧情。
7. 保持仓库 Private；不要在公开仓库或公开链接中发布签约正文。
