## 统一维护规则

1. 事实以 `manuscript/01_80.md` 为准；管理文档必须跟随正文更新。
2. 不另行保留与当前正文冲突的旧版设定、旧版剧情终点或重复的正文副本。
3. 区分正文事实、人物判断和未来计划；未写入正文的内容不得标为已发生。
4. 新增正文后，同步更新章节导航、人物状态、时间线、资源、物件、线索和创作进度。
5. 不确定的细节标记为待定，不用常识或猜测补成事实。
6. 保持仓库 Private，避免公开发布完整创作正文。
