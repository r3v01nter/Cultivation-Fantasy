## 统一维护规则

1. 正文优先；摘要和人物卡不能反过来覆盖正文。
2. 正文未明确的内容标为“待定”，不靠推测补成事实。
3. 区分正文事实、角色判断、作者裁决和未来计划。
4. 新章节写入正文后，再更新导航、台账、人物状态和路线。
5. 旧版或重复资料放入 `archive/legacy/`，注明其非权威性质，不与当前文档并列使用。
6. 不改写已定稿章节，除非作者明确要求。
