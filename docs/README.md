# 仓库导航与维护规则

本仓库当前只以最新版《我在修仙界做实验》第 01—70 章目录与剧情摘要为剧情基线。旧版正文及依赖旧版的时间线、协作材料已经弃用，不得混回新版。

## 当前有效文件

| 文件 | 用途 | 状态 |
|---|---|---|
| [README.md](../README.md) | 项目总览与当前进度 | 有效 |
| [简介.md](../简介.md) | 作品简介与卖点 | 按新版内容整理 |
| [70章总目录与剧情摘要.md](70章总目录与剧情摘要.md) | 第 1—70 章目录、章节标题与剧情摘要 | 当前唯一剧情规划基线 |
| [创作设定总纲.md](创作设定总纲.md) | 根据新版目录重建的设定概要 | 目录未说明处保留待定 |
| [剧情要素台账.md](剧情要素台账.md) | 按新版摘要重建的时间锚点、人物、物件与线索 | 目录摘要级记录，尚非正文核验结果 |

## 当前不在仓库中的内容

- 旧版“沈砚”第 1—30 章正文。
- 旧版前十章时间线核验报告与旧协作交接材料。
- 尚未实际归档的 70 章独立正文、完整总集与分卷合集。

## 维护规则

1. 新增章节正文时，文件名与章节编号以最新版目录为准。
2. 章节摘要不能冒充完整正文；目录中的剧情结论也不能替代逐章核验。
3. 每条台账记录注明来源章节；没有正文来源时，标记为“目录摘要来源”。
4. 如果发现冲突，先核对最新版目录和用户明确裁决，不恢复旧版设定来填空。
5. 只有文件真正提交到仓库后，才把它加入导航。
