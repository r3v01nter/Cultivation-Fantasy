## 使用原则

1. 正文事实优先，摘要、角色卡和台账不得反向覆盖正文。
2. 明确区分正文事实、作者裁决、角色判断和未来计划。
3. 未经作者确认的方案保持提案或待裁决状态。
4. 新正文完成后，再同步更新章节导航、剧情台账、人物状态和创作路线。
5. 旧版资料只用于追溯，不与当前有效文档并列使用。
