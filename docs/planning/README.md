# 未落地企划与未来剧情方案

本目录只放尚未写入定稿正文的提案、人物方案、后续章节规划和待裁决设想。

## 使用边界

- 本目录内容默认是**计划，不是正史**。
- 不得将提案中声称已经发生的事件直接写入第 01—80 章的事实台账。
- 若企划与 [第 01—80 章定稿正文](../../manuscript/01_80.md) 冲突，以正文为准，并把冲突标记出来。
- 任何方案要成为正史，必须先经作者确认，再在后续正文中实际写出；最后更新人物卡、台账和章节导航。
- 方案可以被修改、搁置或废弃，不得因为已存入仓库就自动生效。
