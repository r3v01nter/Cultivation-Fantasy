# 《我在修仙界做实验》创作设定总纲

> **唯一依据：** `manuscript/01_80.md` 第 01—80 章定稿正文。本文记录当前有效设定；不再维护旧版设定或旧进度的兼容条目。正文未明确的部分不擅自补全。

## 一、作品定位

- 类型：实验流修仙、凡人谋略、宗门智斗、无系统成长。
- 主角：沈梦天。
- 核心方法：提出假设、设计实验、记录结果、排错止损、迭代结构。
- 核心主题：以实验理解仙道，以证据和账目判断人心；个人求生逐渐延伸到资源分配、制度与规则。
- 当前正文：第一卷《外院微光》第 01—50 章；第二卷《炉火与暗潮》第 51—80 章。

## 二、主角与故事起点

沈梦天穿越后成为青云宗外院五灵根杂役。五系灵气相互牵制、内耗严重，常规吐纳效率低。他没有系统提供答案，而是依靠观察、实验、资源核算和有限证据寻找生路。

开篇核心事件包括断河谷设局、顾衡死亡、沈梦天护送遗体返回青云宗，以及陆闻的盘问。外院杂务账目、库房夜火、北坡丁字四号矿坑旧案等线索推动早期剧情。角色的怀疑、推测与已经证实的事实必须分开处理。

## 三、修炼与实验体系

## 五、分卷主线

### 第一卷《外院微光》（第 01—50 章）

沈梦天从断河谷事件进入青云宗外院，在陆闻的怀疑、外院资源与账目纠纷中求生。他通过实验逐步改善五灵根修炼，并沿杂务记录、旧档和矿务线索追查北坡丁字四号矿坑旧案。卷末北坡冲突推动其修为和生存能力进一步提升。

### 第二卷《炉火与暗潮》（第 51—80 章）

沈梦天围绕丹房控火、材料回收与五行核心继续实验，逐步建立内景锚点并完成五槽母石脱钩。北坡相关争夺与幽泉宗线索延伸出新的风险。第 71—80 章进入丹器百艺考较，沈梦天在遭遇暗算后炼出九粒云纹上品玄元涤脉丹，最终夺魁并进入内门丹堂，获得独立小院和二品地火实验室。

## 六、写作约束

1. 实验必须有假设、验证、失败成本、资源消耗和迭代过程，不能成为无代价万能破解。
2. 角色推断不自动等于世界真相；关键判断需要证据。
3. 账目、档案、物证和资源分配必须影响实际行动与利益关系。
4. 主角可以设局，但不能让所有人都按其计划行动。
5. 不把章节导航或摘要当作正文；有争议时直接回到定稿正文。
6. 不恢复旧版主角姓名、旧版时间线或与当前正文冲突的旧情节。
