# 《我在修仙界做实验》创作设定总纲（新版基线）

> 版本：按最新版《第 01—70 章目录与剧情摘要》整理。
> 本文件只记录新版目录明确支持的内容。目录未说明的部分标记为待定，不从旧版设定补入。

## 一、作品定位

- 类型：实验流修仙、凡人谋略、宗门智斗、无系统成长。
- 主角：沈梦天。
- 核心叙事方法：提出假设、设计实验、记录结果、排错止损、迭代结构。
- 核心主题：以实验拆解仙道，以证据和账目丈量人心；火种不应永远掌握在一个人手里，而应让更多人学会生火。
- 当前规划范围：第一卷《外院微光》第 1—50 章；第二卷《炉火与暗潮》第 51—70 章。

## 二、主角与开篇处境

沈梦天是穿越者，进入青云宗外院，身份为五灵根杂役。五灵根的主要困境是五系灵气入体后相互牵制、内耗严重，常规吐纳效率低。

主角冷静克制、善于计算与设局，但不是全知全能。关键判断需要依赖有限证据；实验会失败，身体与资源会付出代价。主角不依靠系统直接获得答案。

新版目录的开篇事件是：沈梦天在断河谷设局，导致内门天骄顾衡死亡，随后护送顾衡遗体返回青云宗。顾衡之死、北坡旧案与主角的真实责任构成故事的重要线索。

## 三、核心修炼体系：五灵根五行核心

### 1. 迭代阶段

| 章节范围 | 修为/结构进展 |
|---|---|
| 第 1—10 章 | 炼气二层；右路局部“土四木三”双息微循环，持续约 3—5 息 |
| 第 11—30 章 | 炼气三层；下丹田土木外环约 10—30 息，初步测试水息介入阈值 |
| 第 31—50 章 | 炼气四层；借赤铁伴生髓与五槽原生矿髓母石，建立水、土、木三息常驻内景闭环，并推演杀招“水火寸劲” |
| 第 51—60 章 | 炼气五层；确立“左金水、右木火、中土隔绝”的空间拓扑，建立第一代五行核心（五槽母石外挂版），五池同转达 50 息 |
| 第 61—70 章 | 炼气五层巅峰；以五息定脉散推动核心去外挂化，形成中枢土锚与太阴水金双生锚，嵌合次生太阴煞髓晶后五池同转突破 80 息 |

### 2. 已出现的重要术语

- 五灵根杂息归寂法
- 定息镜（目录将其拆解为气血与灵息谐振机制）
- 土木外环、木裹水、水息阈值
- 赤铁伴生髓、五槽原生矿髓母石
- 五行核心、五息定脉散、中枢土锚、太阴水金双生锚
- 水火寸劲、太阴煞髓晶、次生太阴煞髓晶

这些术语以新版目录中的用法为准。更细的机制、限制与代价若目录未明确，不在此擅自补设。

## 四、主要人物与势力（仅记录新版目录明确内容）

- **沈梦天**：主角，五灵根杂役，以实验推进修炼。
- **顾衡**：内门天骄，开篇死亡；其死与断河谷事件有关。
- **陆闻**：内门精英，持续对沈梦天施压与盘问。

## 五、两卷主线

### 第一卷《外院微光》（第 1—50 章）

沈梦天从断河谷事件进入青云宗外院。面对陆闻的怀疑，他以证据、账目和灵息实验寻找生路；外院杂务房的账目问题逐渐牵出北坡丁字四号矿坑旧案。修炼上，他从土木双息微循环逐步推进到水、土、木三息常驻闭环。卷末北坡暴雪竖井冲突中，他反杀严嵩麾下两名炼气六层心腹，晋升炼气四层后全身而退。

### 第二卷《炉火与暗潮》（第 51—70 章）

沈梦天接手三号丹房退灰差事，收集丹炉赤铜微丝与紫金铁精砂，完成五槽母石与五行核心的关键迭代。苏泠以器物因果回溯术追查异常；冬至北坡争夺中，沈梦天针对魔道幽泉血引丝进行预先处理，并在体内形成永久内景锚点。第 70 章结束时，周通伏诛、严嵩被革职囚于思过崖，沈梦天达到炼气五层巅峰，目标指向开春内门丹器百艺考较。

## 六、写作约束

1. 不把实验写成无成本的万能破解；必须保留失败、验证、损耗与风险。
2. 角色推断不自动等于世界真相；线索需要证据支撑。
3. 账目、档案、物证和资源分配应实际影响人物行动与利益关系。
4. 主角可以设局，但不能让所有人都按其计划行动。
5. 不得把章节摘要冒充完整正文。
6. 旧版主角“沈砚”及与旧稿绑定的情节、时间线和人物关系不再作为当前设定来源。
