## 固定协作流程

1. ChatGPT根据当前项目状态编写中文任务书，保存为独立的Markdown文件。
2. ChatGPT在回复中提供任务书GitHub页面地址和Raw下载地址。
3. 作者将任务书地址或下载文件交给Gemini；Gemini自行浏览仓库相关资料并按任务书执行。
4. Gemini完成后，将整理好的文件直接发送给作者，不直接写入、提交或清理GitHub仓库。
5. 作者检查交付文件，并手动提交至 `inbox/gemini/待交付/`。
6. ChatGPT读取待交付文件，独立审查；需要返工时发布修订任务，通过后再原样归档并更新索引。
7. 每轮验收结束后，ChatGPT发布下一轮中文任务书，并提供页面链接与可下载链接。

## 执行边界

- Gemini只读取仓库资料、执行任务、生成并发送交付文件；不拥有仓库写入权限。
- 作者保留交付提交权和最终裁决权。
- ChatGPT负责任务书、独立审查、归档、索引和项目文档维护。
- 历史任务书不覆盖、不删除；新任务使用新版本文件。
- “已完成”“已交付”“已归档”“审查通过”“作者批准”是不同状态，不得混为一谈。
- 未经作者确认的方案不得写入正式设定或标记为正史。
