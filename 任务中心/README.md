# 任务中心

这是本仓库交给Gemini、ChatGPT或其他执行模型使用的统一任务入口。

## 执行模型的固定操作

每次接到本仓库任务时，按以下顺序执行：

1. 先完整阅读本目录的[当前任务.md](当前任务.md)。
2. 打开其中指定的任务书，严格按任务书列出的范围、来源、交付清单和禁止事项执行。
3. 需要查资料时，优先使用仓库内被任务书明确指定的文件；不要把旧归档当作最新事实。
4. 不得自行更改作者裁决、正文事实、历史归档或任务边界。
5. 完成后，将所有交付文件直接放入 `inbox/gemini/待交付/` 根目录；不要创建子目录，不要自行归档。
6. 在交付README中列出文件名、用途、完成情况、未解决问题和证据来源。
7. 交付完成后停止，不要覆盖或清理其他文件。

## 作者给Gemini的最短指令

> 请打开仓库 https://github.com/r3v01nter/Cultivation-Fantasy ，先阅读“任务中心/当前任务.md”，再按里面指定的任务书执行。完成后把全部交付文件直接放入 inbox/gemini/待交付/，不要改动历史归档、V1正文或正式设定。

## 任务入口

- [当前任务](当前任务.md)：唯一当前任务指针。
- [任务书目录](任务书/README.md)：历次正式任务书索引。
- [交付入口规则](../inbox/gemini/README.md)：交付文件如何投放与后续归档。
- [历史交付归档](../archive/gemini/README.md)：查看历次交付与独立审查状态。

## 规则

- 当前任务只由作者/GPT维护；执行模型不得自行切换当前任务。
- 历史任务书保留原样；新任务使用新版本文件。
- “已完成”“已交付”“已归档”“审查通过”“作者批准”是不同状态，不得混为一谈。
