# 《我在修仙界做实验》

原创中文修仙小说，核心方向是**实验流修炼、凡人谋略、宗门博弈与制度探索**。

## 项目概况

- **V1历史正文：** 第01—80章，作为只读历史基线保存。
- **V2重构方向：** 从第01章重新规划，当前规划范围为第01—120章；后续逐步扩展全书主线。
- **创作状态：** 设定校订与前期重构中，规划稿不等于正式正文。
- **当前任务：** V6.8.9多维证据状态隔离与审查返修；V6.8.8已归档，独立审查不通过。

## 主要创作方向

- **修炼逻辑：** 主角沈梦天以观察、假设、实验、验证和迭代探索五灵根修炼路径；能力成长必须有过程、成本和失败风险。
- **人物与谋略：** 主角有明确底线，重视证据、资源、组织与利益关系，不是全知全能的棋手。
- **世界主线：** 从个人求生和宗门内部博弈，逐步延伸至组织建设、文明冲突、量劫机制与世界深层真相。
- **叙事原则：** 通过剧情呈现制度、资源分配和群体关系，不用设定讲解代替故事。

## 仓库结构

- `manuscript/`：历史正文。
- `characters/`：人物资料。
- `docs/`：当前管理文档、正式设定和待落地企划。
- `任务中心/`：当前任务指针与历次中文任务书。
- `inbox/gemini/待交付/`：作者手动提交的临时交付区。
- `archive/gemini/`：各版本原始交付及独立审查记录。
- `archive/legacy/`：整理前的历史副本，仅供追溯，不作为当前依据。

## 资料优先级与维护规则

1. **正文事实以正文为准。** V1第01—80章发生过的剧情，以 `manuscript/01_80.md` 为准。
2. **作者裁决优先。** 已确认事项以作者裁决日志为准；未经确认的提案不得写成既定设定。
3. **规划与正史分离。** V2规划稿、人物方案和实验推演不自动成为正文事实。
4. **历史交付原样保存。** 原始交付不润色、不覆盖；归档不代表审查通过。
5. **交付职责分离。** Gemini只负责按任务书生成文件、自检并打包发送给作者；作者解压后将本轮文件整体提交到待交付区，无需逐份分类或改名；ChatGPT负责读取、独立审查、整理归档、清理待交付区并发布下一轮任务书。
6. **公开仓库注意隐私。** 不提交密码、访问令牌、私人联系方式或其他不应公开的信息。
