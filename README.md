## 故事简介

沈梦天穿越成青云宗外院一名五灵根杂役。别人把五灵根视作修行绝路，他却把身体和修仙天地当作实验室：记录失败、拆解灵息运行、验证五行相克的边界，再用一次次实验搭建自己的五行核心。

他靠的不是系统，也不是无代价的奇遇，而是对资源、证据、风险和人心的计算。从断河谷旧案到外院杂务账目，再到北坡矿坑与冬至暗潮，他一边寻找活路，一边逐步触碰宗门长期掩埋的秘密。

## 当前剧情进度（依据最新 70 章目录稿）

- **第 1—50 章：第一卷《外院微光》**。主线围绕顾衡之死、沈梦天进入青云宗、外院账目调查及北坡丁字四号矿坑旧案展开；卷末沈梦天晋升炼气四层。
- **第 51—70 章：第二卷《炉火与暗潮》**。沈梦天在三号丹房继续完善五行核心，卷入苏泠的器物因果追查与冬至北坡争夺；第 70 章结尾达到炼气五层巅峰，并将目标指向开春内门丹器百艺考较。
- 最新目录稿标注全书约 **18.5 万字**。该数字和“定稿”状态尚未通过仓库内 70 章正文逐章核验。

## 写作原则

1. 主角谨慎、冷静，但不全知；谋划必须有信息来源、成本和失败风险。
2. 五行核心是逐步验证的研究成果，不是无代价的天赐外挂。
3. 资源分配、制度变化与权力关系要通过具体实践和利益冲突呈现。
4. 人物关系保留各自目标与代价，不因感情自动原谅主角。
5. 重大灾难由自然变化与文明冲突共同推动，不把一切都归结为单一幕后黑手。
6. 设定冲突先记录并复核，不擅自把推测写成已确认事实。
