## 故事简介

沈梦天穿越成青云宗外院一名五灵根杂役。他把自己的身体和修仙天地当作实验室：记录失败、拆解灵息运行、验证五行相克的边界，再通过一次次实验搭建自己的五行核心。

他依靠证据、实验、资源核算和风险判断求生，而不是依赖系统直接给答案。故事从外院杂役生活、顾衡之死与北坡矿坑旧案，推进到五行核心迭代、丹房控火和内门丹器百艺考较。

## 当前进度

第一卷《外院微光》第 01—50 章；第二卷《炉火与暗潮》第 51—80 章。第 80 章结尾，沈梦天修为达到炼气六层，成为内门丹堂正式弟子，并获得独立小院与二品地火实验室。
