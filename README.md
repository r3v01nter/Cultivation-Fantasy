## 当前剧情锚点

第 80 章结束时，沈梦天夺得百艺考较魁首，晋升青云宗内门丹堂正式弟子，修为炼气六层，神识四丈五尺，入驻翠微峰丙字十二号独立小院，拥有二品地火实验室与独立护院阵。五槽母石已彻底脱钩，当前以内景三锚架构为准。具体状态以正文和剧情台账为准。

## 文件使用规则

1. **正文唯一来源：** `manuscript/01_80.md`。未经作者明确要求，不改写已定稿章节。
2. **正文优先于摘要：** 章节导航、人物卡和剧情台账是辅助资料；冲突时回到正文核对。
3. **事实与计划分离：** 未写进正文的方案不得记为已发生。尤其是 `docs/planning/` 中的提案，默认不具备正史效力。
4. **不删除历史材料：** 发现重复或旧版资料时，先移入归档并注明用途，不直接销毁可能有价值的内容。
5. **每次新增正文后：** 同步章节导航、剧情要素台账、人物状态和创作路线。
6. **隐私：** 本仓库包含完整小说正文，建议保持 Private，避免未经授权公开。

## 维护入口

需要判断“已经发生什么”时，先读正文；需要判断“人物/资源/线索当前状态”时，读剧情要素台账；需要决定“下一步写什么”时，读创作路线与进度；需要查看未定方案时，再进入 `docs/planning/`。
